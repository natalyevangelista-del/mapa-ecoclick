# EcoClick — Pontos de coleta

Projeto pronto para abrir no VS Code.

## Arquivos
- index.html — página completa com HTML, CSS e JavaScript.

## Como abrir
1. Extraia esta pasta.
2. Abra a pasta `EcoClick` no VS Code.
3. Abra `index.html`.
4. Para visualizar, use o Live Server ou abra o arquivo no navegador.

O projeto utiliza Leaflet e OpenStreetMap por CDN/internet.
